# N=9 での「標準形 ⇔ 値が新しい」の検査

2026-10-24。値は変更していない `token_value.index`。
対象は A0, A1, A2, A3, E1, W の9トークン以下で、直前の接頭辞が標準な非空語。
全132,954語（標準58,322語、非標準74,632語）を検査した。
標準な接頭辞の判定は `stdtok-9.json.gz`。

比較相手は同じデータの標準語58,323語（空列を含む）。
生の整数列の辞書順で並べ、各位置の左側の値の最大と右側の値の最小を使う。
自分自身は除く。したがって、近い相手だけでなく全標準語との比較になる。
相手の値の単調性は仮定せず、別に検査する。

## 元の範囲だけでの混同行列

| 実際 | 値が新しい | 値が新しくない |
| --- | ---: | ---: |
| 標準 | 58,322 | 0 |
| 非標準 | 135 | 74,497 |

非標準語の内訳は、上側だけで失敗72,440、下側だけで失敗2,057、
両側で失敗0、両側を通る135。
元の標準語の隣接順序違反は0件。

## 範囲外の相手の直接確認

135件すべてについて、値を使わず `std.ceil(raw)` で直上の標準形を求め、
その標準性を `std.is_standard` でも確認した。
その列を再びトークンに分け、`token_value.index` で値を直接計算した。

全135件で、相手は元の語より真に大きく、値は等しかった。
相手はすべてアルファベットの外の A4 を含む。
異なる相手は117語で、長さは1〜7トークン。
したがって今回はトークン数の上限による不足ではなく、A4 がないことによる不足だった。

例（先頭0021を省略）:

- A3 W W と A4 は同じ値。
- W A3 W W W と W A4 は同じ値。
- A3 W A3 W W と A4 は同じ値。

不一致135件の長さ別内訳は、長さ3が1、5が2、6が4、7が12、8が31、9が85。
全件の生の列・値・直上の相手・標準性検査結果は `value-new9.json` に記録した。

確認した117語を比較相手に加えると、標準語は58,440語となり、
この集合の隣接順序違反も0件。
既存標準語の判定を壊さず、残り135件すべてを値の一致で除ける。

| 実際 | 値が新しい | 値が新しくない |
| --- | ---: | ---: |
| 標準 | 58,322 | 0 |
| 非標準 | 0 | 74,632 |

範囲外の相手を確認した後の説明不能な不一致は0件、未解決も0件。
これは上記有限集合についての結果で、一般の特徴付けの証明や D 領域の検証ではない。
